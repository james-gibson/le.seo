A tree asks two questions and refuses a third. It does not ask "who are you" in general; it asks
what you are doing here, and what you want to leave with.

## The four voices

| voice | who | asks for |
| --- | --- | --- |
| `reader` | reads the concepts; will not run anything | a page, and an honest one |
| `grower` | wants to run one, or start one from a template | a start, without a detour |
| `maintainer` | keeps a site true to the rules it claims | the source of the claim |
| `packager` | designs the next seed, or the isotope it should ship | the shape, and the cost |

## The four goals

| goal | what the visit should achieve | the verb |
| --- | --- | --- |
| `try` | open one and use it | open |
| `adopt` | take it into something you already run | install |
| `verify` | check a claim against its source | read |
| `fund` | decide whether the cost is worth it | decide |

A goal is a verb in the same sense a seed has one: it says what the reader does next, not what the
page says. Two goals that describe the same action are one goal, and a voice that never has a goal
of its own is an audience nobody is pitching to.

## Why the pair, not a persona

A persona is a paragraph an agent cannot check. A pair of values is two columns and a lookup: a
tree either has a link for this voice and this goal, or it falls back and says so. That is the
difference between a marketing page and a marketing claim.
